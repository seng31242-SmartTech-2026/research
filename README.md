# research — SmartTech

This repository contains all **research and fact-finding artefacts** gathered during the analysis phase of the SmartTech project (SENG 31242 – System Design Project, University of Kelaniya, 2026).

---

## Repository Purpose

The `research` repository stores the raw evidence and analysis that feeds into the Software Requirements Specification (SRS). It provides a transparent, auditable record of how the team identified the problem, validated the need, and understood the domain.

All artefacts here must be committed within **24 hours** of the activity that produced them.

---

## Contents Structure

```
research/
├── literature-review/
│   ├── literature-review.md        # Summary of academic and industry sources
│   └── references.md               # Full reference list (author-date format)
│
├── competitive-analysis/
│   ├── competitive-analysis.md     # Feature comparison matrix + gap analysis
│   └── screenshots/                # Screenshots of competitor products (with date)
│
├── client-interviews/
│   ├── interview-guide.md          # Question guide used before each interview
│   ├── interview-01-YYYY-MM-DD.md  # Transcript or structured summary per session
│   ├── interview-02-YYYY-MM-DD.md
│   └── ...
│
├── surveys/
│   ├── survey-instrument.md        # Survey questions as administered
│   ├── responses-anonymised.csv    # Anonymised raw responses
│   └── survey-summary.md           # Statistical summary and key findings
│
├── observation/
│   ├── observation-protocol.md     # Protocol used during field observation
│   └── field-notes-YYYY-MM-DD.md   # Field notes per session
│
└── workshops/
    ├── workshop-agenda.md           # Workshop agenda
    ├── attendance-sheet.md          # Attendee names and roles
    └── output-affinity-map.md       # Affinity map or other output artefacts
```

> Add folders only for techniques actually used. At least **two** fact-finding techniques must be documented with full evidence as required by the course guideline (Section 6.1).

## Fact-Finding Techniques Covered

| Technique | Documentation Required | Status |
|---|---|---|
| Structured Interview | Interview guide, transcript/summary, key findings | ☐ |
| Questionnaire / Survey | Survey instrument, anonymised responses, statistical summary | ☐ |
| Document Analysis | List of documents reviewed, key data extracted | ☐ |
| Observation | Observation protocol, field notes, photographs (with consent) | ☐ |
| Workshop / Focus Group | Agenda, attendance sheet, output artefacts | ☐ |
| Competitive Analysis | Feature comparison matrix, screenshots, summary of gaps | ☐ |

Update the Status column to ✅ as each technique is completed.

## Privacy & Ethics

- All interview transcripts must be anonymised or have written consent from the participant on record.
- Survey responses must be stored in anonymised form — no names or identifying information.
- Photographs taken during observation sessions require participant consent. Document consent in the observation protocol.
- Do not commit any personally identifiable information (PII) to this repository.
